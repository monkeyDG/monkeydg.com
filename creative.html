B1

Planetside Open Games

POG is a matchmaking system for Planetside 2's dev-sanctioned competitive server. Our 3-person dev team built a fully cloud-hosted Discord bot in Python, with MongoDB for data processing and storage.

The bot talks to the game's API for scoring, Google Sheets for map reservations, and TeamSpeak 3 for match notifications.

B2

The Voron 2.4 is a community-developed 3D printer. It uses a CoreXY motion system with a belted gantry, and dual MCUs controlled by a Raspberry Pi running Klipper.

I forked the project to design and build the Voron 2.4 XL. I modified the motion system, added dual linear rails, doubled the extrusion thickness, and reconfigured the firmware to handle the bigger volume.

DGallo.ca / Monkeydg.com

I designed, built, and deployed the site you're on. The first version was hand-written HTML, CSS, and jQuery, back when that was the only way to do it. This redesign I made with Claude Code, which felt fair given my day job.

It's a static site in S3, with DNS on Route 53, CloudFront as the CDN, and the contact form running on Lambda and SES. GitHub Actions deploys it on every push.
