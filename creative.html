AVRA is an Ottawa-based 5-piece rock band, drawing inspiration from Led Zeppelin, U2, and The Black Keys. I'm on drums.

We've played all over Ottawa, from Petrie Island Beach on Canada Day, to RBC Bluesfest 2017, to an out-of-the-way chip truck rally with 15 people that our guitarist promised would be our big break (...it wasn't).

Planetside Open Games is a matchmaking system for Planetside 2's dev-sanctioned competitive server. We've run over 5000 matches with over 3000 hours of match time.

Our 3-person dev team built a fully cloud-hosted Discord bot in Python, with MongoDB for data processing and storage. The bot talks to the game's API for scoring, Google Sheets for map reservations, and TeamSpeak 3 for match notifications.

Built before AI could write the code for me. Every bug in here is handmade.

The Voron 2.4 is a community-developed 3D printer that uses a CoreXY motion system with a belted gantry and dual MCUs, controlled by a Raspberry Pi running Klipper.

I forked the project to design and build the Voron 2.4 XL: a printer with 400mm3 of internal build volume and up to 150mm/s of print speed. I modified the motion system, added dual linear rails, doubled the extrusion thickness, and reconfigured the firmware to handle the bigger volume.
