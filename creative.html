02 · Software

Planetside Open Games

A matchmaking system for Planetside 2's developer-sanctioned competitive server. In its first year it ran over 5,000 matches and more than 3,000 hours of match time.

Our three-person dev team built a cloud-hosted Discord bot in Python, with MongoDB for data processing and storage. It integrates with the game's API for scoring, Google Sheets for map reservations, and TeamSpeak for match notifications.

04 · Hardware

Voron 2.4 XL

The Voron 2.4 is a community-designed Core-XY 3D printer with a belted, flying gantry and dual MCUs, driven by a Raspberry Pi running Klipper.

I forked the design to build an XL version: I modified the motion system, added dual linear rails, doubled the extrusion thickness, and reconfigured the firmware for the larger build volume.

06 · Web

This website

Designed and hand-coded from scratch with no frameworks or libraries: semantic HTML, one stylesheet of design tokens, and a few small vanilla JavaScript modules, with light and dark themes and full keyboard support.

Every push to master deploys through GitHub Actions to S3, served by CloudFront with Route 53 DNS. The contact form posts to a Lambda function that sends mail through SES.
